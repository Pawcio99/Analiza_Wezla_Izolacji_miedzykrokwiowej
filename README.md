# Styk ściany szczytowej z połacią dachu jako węzeł wielofizyczny

Statyczna strona publikacji naukowo-technicznej Pawła Majsterka, przygotowana do hostowania przez GitHub Pages.

## Lokalny podgląd

Otwórz `index.html` w przeglądarce albo uruchom:

```bash
python3 -m http.server 8000
```

i wejdź na `http://localhost:8000`.

## Publikacja na GitHub Pages

1. Umieść pliki w repozytorium.
2. W GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**.
3. Wybierz gałąź `main` i katalog `/ (root)`.

## Pliki

- `index.html` — publikacja i semantyczna struktura strony,
- `styles.css` — styl naukowy / czytelność tekstu,
- `script.js` — postęp czytania, aktywny spis treści, kopiowanie cytowania, druk/PDF,
- `LICENSE.md` — niestandardowe warunki publikacji i wykorzystania komercyjnego,
- `CITATION.cff` — metadane cytowania dla GitHub.
